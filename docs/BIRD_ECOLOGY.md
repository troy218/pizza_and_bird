# 지형 연동 탐조 출현 (2026-09-27)

## 참고 자료와 한계

- [1](http://www.birdskorea.org/Birds/Birding_in_Korea/BK-BK-Birdyear.shtml) Birds Korea, **The Korean Birdwatcher's Year**: 한국의 공원·성숙한 숲·하천·갯벌에 따른 조류 분포와 계절 이동을 설명한다. 까치·참새 같은 흔한 생활권 조류, 숲의 박새류/딱다구리류, 물가의 오리/왜가리 등을 지형 연동의 정성적 근거로 사용했다.
- [2](https://ebird.org/science/status-and-trends/faq) Cornell Lab, **eBird Status and Trends FAQ**: 상대 풍부도는 표준화된 탐조 노력(현재 FAQ: 전문가의 1시간·2km 탐조, 종별 최적 시간대) 아래 발견되는 개체 수의 추정값이다. 모델에는 시간대·날씨·지역 서식지·고도·지형 등이 포함된다. 이를 게임의 실시간 출현 확률로 직접 환산할 수 없다.

**아래 초 단위 간격·등급 비중·타일 거리·체류 시간은 실측 통계가 아니라 5분짜리 게임 하루에 맞춘 설계값이다.** eBird 자료를 다운로드/적합한 통계 모델이 아니다. 기존 598종의 과/서식지/계절/지역 데이터를 사용한 간략 모델이며, 모든 종의 미소서식지와 국내 관찰 빈도를 검증한 것은 아니다. 조석·수심·실제 개체군 크기·무리 행동은 아직 모델링하지 않는다. 물가 1타일을 얕은 물의 대용으로 사용하며, 숲새는 나뭇가지 위가 아니라 나무 주변 지면에 배치한다.

## 위치

`BirdEcology.suitability`를 출현과 평상시 이동 양쪽에서 사용한다. `BirdEcology.regionAllows`는 큰 지역 범위를 먼저 판정하고, 종별로 `onlyRegions`가 있으면 그 지역만 허용한다. 지역 태그는 넓은 생태 유형이므로 명시 범위가 우선하며, 마지막에는 아래 타일 적합도도 통과해야 한다.

- 두루미·재두루미는 철원·임진강·공릉천·순천만·주남·금강 하구, 흑두루미는 순천만·주남·금강 하구 중심으로 제한한다. 따오기·저어새·가창오리·물수리·검은머리물떼새·붉은어깨도요 등도 대표 탐조지 범위에서만 후보가 된다.
- 일반 종은 32개 지역의 서식지 태그로 거르고, 추가 지역 가중치와 종별 핫스팟으로 실제 선택 빈도를 조정한다. 이 가중치는 스폰 선택과 도감의 `찾기 좋은 지역` 순위가 공유한다.
- 도감 위치는 가능한 계절·시간대에서 게임의 지역/서식지 가중치를 비교해 상위 3곳을 보여준다. 실제 관찰 통계나 퍼센트 확률은 아니며, 현재 계절·날씨·타일에 따라 체감 출현은 달라진다.
- 오리·논병아리·아비·가마우지류/물닭: 수면 우선, 물가 2타일 내 자연 지면 보조.
- 백로·저어새·도요/물떼새류·물총새: 물가 자연 지면 또는 육지 바로 옆 수면. 광장/깊은 수면 중앙 제외.
- 두루미류: 물 또는 갈대 주변 풀밭/갈대밭.
- 갈매기류: 수면/물가 또는 해안 지역의 모래.
- 박새·딱다구리·동고비·오목눈이·동박새·팔색조류: 나무 2타일 이내 자연 지면.
- 개개비·휘파람새·붉은머리오목눈이과: 갈대/키 큰 풀 또는 갈대 주변 지면.
- 나머지는 기존 서식지 태그를 실제 나무·바위·산·물·갈대·모래·초지·포장 타일과 대응한다.
- 건물·현관·터널·실내·소품 위 출현 금지. 사람의 물 타일 충돌 판정은 그대로 유지한다.
- 이동 판정은 크기가 다른 스프라이트 좌상단이 아니라 발 위치를 기준으로 한다. 도망 비행은 지면 조건을 따르지 않는다.

## 빈도

- 입장 직후 2마리 강제 출현 제거. 후보가 없을 때 반대 밤낮/계절의 새로 대체하지 않는다.
- 평균 **출현 시도** 간격(맑음): 새벽 12초, 일반 낮 19초, 11~15시 28초, 황혼 17초, 밤 48초.
- 비 ×1.7, 강풍 ×1.9, 눈 ×1.5. 흐림은 맑음과 동일.
- 고정 주기 대신 최소 4초 + 지수분포 대기. 적합한 새/타일이 없거나 개체 상한(3)에 도달하면 아무것도 나오지 않아 실제 발견 간격은 더 길다.
- 먼저 등급을 추첨: 기본 COMMON 86 / UNCOMMON 12 / RARE 1.8 / LEGEND 0.2. 목록에 희귀종이 많다는 이유만으로 전체 출현이 희귀종에 치우치지 않는다. 해당 등급에 후보가 없어도 다른 등급으로 재추첨하지 않는다.
- 행운은 등급 질량을 소폭 증가(최대 희귀 ×1.5, 전설 ×1.75 후 정규화). 서식지·계절·시간 제약을 무시하지 않는다.
- 등급 안에서 기존 종별/지역/계절/날씨 가중치로 선택, 80개 무작위 타일 후보에 적합도와 기존 거리/개체 간격 조건 적용. 확정 출현 비율은 위 등급 추첨 비율과 다르다.
- 55~120 월드 초 후 자연 이탈해 멈춰서 기다려도 같은 3마리가 영구적으로 자리를 차지하지 않는다. 촬영 모드의 기존 월드 감속 적용.
- 흰뺨검둥오리·원앙·괭이갈매기 등 일부 텃새를 과 단위 철새 규칙이 숨기던 계절 분류 수정.
