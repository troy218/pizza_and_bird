## 1. 컨셉

- **한 줄 정의**: 피자를 굽고, 탐조를 하는 한국 배경 픽셀 힐링 게임
- **감성**: 아기자기한 픽셀 아트, 느긋한 속도, 수집의 즐거움, 실제 한국 지역 여행의 정취
- **플랫폼**: Android (오프라인 전용, 권한 없음)
- **수익 모델**: (출시 후 결정 — 유료 앱 or 광고 없는 무료)

## 2. 핵심 시스템

### 2.1 배고픔 수치 (hunger, 0~100)
- 이동/자전거로 서서히 감소 (자전거가 더 빨리 감소)
- 0이 되면 이동 속도 45% 감소 ("배고파요…" 경고)
- 피자 섭취로 회복

### 2.2 행운 수치 (luck, 0~100)
- 새로운 새 첫 발견 +4, 피자 섭취(+5~+18), 잠자기 +5로 상승
- 시간이 지나면 천천히 감소
- **희귀새 스폰 가중치 배율**: `weight × (1 + (luck/100) × (tier-1) × 1.4)`
  - 예) 행운 100에서 전설(4성) 새는 기본 대비 약 5.2배 자주 출현
- (추후) 집 장식 소품이 행운 상승 효과를 갖는다

### 2.3 피자
- 집의 **화덕**(기본 제공)에서 굽기 미니게임
  - 좌우로 움직이는 커서를 초록(걸작)/노랑(맛있음)/빨강(살짝 탐) 구간에서 정지
  - 품질: 살짝 탄(+20/+5) / 맛있는(+38/+10) / 걸작(+60/+18) — (배고픔/행운)
- 최대 6개까지 들고 다니며 이동 중에도 먹을 수 있음
- **추후**: 도우/토핑 종류, 지역 특산 피자, 재료 쇼핑

### 2.4 탐조 & 카메라
- 필드에 새가 스폰됨 (지역별 서식지 풀 + 등급별 가중치)
- 새는 플레이어가 가까이 오면 도망 (등급이 높을수록 민감, 자전거 탑승 시 더 민감)
- 📷 **카메라 모드**: 시간이 35%로 느려지고, 새의 경계 범위도 40% 감소
- 촬영 반경 내 새를 탭 → 거리 기반 별점(1~3성) + 카메라/행운 보너스
- **카메라 등급** (사진용품점에서 ₩으로 업그레이드):
  | Lv | 이름 | 촬영 반경 | 가격 |
  |---|---|---|---|
  | 1 | 폰 카메라 | 4.5칸 | 기본 |
  | 2 | 컴팩트 카메라 | 6.0칸 | ₩800 |
  | 3 | 미러리스 | 7.5칸 | ₩2,500 |
  | 4 | DSLR | 9.0칸 | ₩6,000 |
  | 5 | 프리미엄 DSLR | 11.0칸 | ₩15,000 |
- Lv3+부터 별점 상승 확률 보너스

### 2.5 도감
- 새별 **촬영 횟수** 누적 기록
- 첫 발견 시 ✨표시, 미발견은 "???"로 표시
- 촬영한 새 정보(설명/등급/서식지) 열람

### 2.6 보리 박사 (조류학자 NPC)
- 각 지역 광장에 상주, 의뢰가 없으면 머리 위에 "!" 표시
- 의뢰: "이 지역의 ○○를 찍어다 주게" → 지역 새 풀에서 선택
  - 아직 찍지 않은 흔함/보통 새를 우선 제안 (55% 확률)
- 의뢰 새를 촬영하는 순간 **자동 완료 & 즉시 보수 지급** (3성이면 +30% 보너스)
- 의뢰는 전역 1개만 유지, 언제든 포기 가능

### 2.7 지역 이동 (포켓몬 스타일)
- **자전거**로만 이동 (B 버튼 탑승, 속도 약 1.75배)
- 지도 가장자리의 **터널**로 들어가면 연결된 지역 맵 로딩 (페이드 전환)
- **텔레포트 기능 없음** — 반드시 터널을 경유
- 부산↔제주는 해저 터널 (스토리상 자전거 여행자의 무모한 도전)

### 2.8 집 & 이사
- 새 게임 시작 시 **9개 지역 중 원하는 곳에 정착**
- 집 내부: 화덕(기본) / 침대(수면+저장, 행운+5) / **이사 박스** / 장식 슬롯 3곳
- 이사: 방문한 적 있는 지역으로 ₩300에 이전 (집 내부는 동일하게 유지)
- 장식 슬롯: 여행지 소품 배치 기능은 **추후 업데이트**

### 2.9 경제
- 수입: 박사 의뢰 보수 (흔함 ₩300 ~ 전설 ₩6,000)
- 지출: 카메라 업그레이드, 이사 비용
- (추후) 사진 판매, 피자 재료 구매

- 방문한 지역끼리 연결선 표시

## 4. 기술 설계

- **엔진**: 외부 엔진 없음 — `SurfaceView` + `Canvas` 커스텀 루프 (완전 오프라인, APK 최소화)
- **가상 해상도**: 480×270 (16:9) → 화면 크기로 최근접 이웃 업스케일 (픽셀 느낌 유지)
- **아트**: 모든 스프라이트/타일을 **코드로 생성** (`Assets.kt`) — 이미지 리소스 0개, 런처 아이콘만 Python 스크립트로 생성
- **맵**: 지역별 시드 기반 절차 생성 (40×30 타일, 16px/타일) — 결정적(같은 지역은 항상 동일)
- **맵 구조**: 중앙 광장(집+NPC) + 십자 도로 + 가장자리 터널/바다/산맥
- **저장**: SharedPreferences + JSON (버전 필드 `v`로 마이그레이션 지원)
- **CI**: GitHub Actions — push 시 debug/release APK 빌드, `v*` 태그 시 Release 발행
- **테스트**: `tools/MapTest.kt` — 81개(9지역×9홈) 맵 조합 + 스폰/경로/경계 자동 검증

## 5. 추후 업데이트 계획 (요청 반영 대기)

1. **새 종류 확장** — 계절/시간대 출현 조건, 30종 이상
2. **피자 종류** — 레시피 조합, 지역 특산 토핑, 굽기 난이도
3. **집 꾸미기** — 여행지 기념품 소품 (장식 슬롯에 배치), 행운 보너스
4. 낮/밤 & 계절 — 밤에 부엉이, 겨울에 두루미 등
5. 사진 앨범 — 찍은 사진 저장/열람, 평점에 따른 판매
6. 배경음악/효과음 (지역별 테마)
7. 업적 시스템, 통계 (총 이동 거리, 총 촬영 수 등)
8. 태블릿/폴더블 대응, 세로 모드 검토
