## 카메라 자료에서 뽑은 것 → 게임에 반영한 것

### 1. 가격을 올리는 요인 (실제 시장 관측)

| 요인 | 실제 데이터 | 게임 반영 |
|---|---|---|
| **센서 크기** | 풀프레임 중앙값 350만 / APS-C 151만 → **×2.3**. 최저가끼리 169만 vs 80만(×2.1), 최고가끼리 869만 vs 334만(×2.6) | 바디 가격이 센서 급으로 층을 이룬다 (M10 ₩30만 → Z6 ₩82만 → MF100 ₩300만) |
| **IBIS 유무** | APS-C 에서 손떨방 있음 ≈ ×1.7 | 보정 없는 저가 바디(₩24~48만)와 있는 중급기(₩56만~)의 간격으로 표현 |
| **렌즈 = 유리 값** | 렌즈 가격 ≈ 무게^0.9 (R=0.90) | 무거운 망원·대구경일수록 급격히 비싸진다 |
| **망원 + 조리개** | 400mm+ 급 ≈ 70-200 F2.8 의 1.5배 / 초망원 대구경 단렌즈 ≈ 초망원 줌의 **5배** | 200-600mm ₩64만 ↔ 600mm F4 ₩310만 (약 5배) |
| **바디 : 렌즈 배분** | 입문 렌즈/바디 = ×0.37, 최고가 렌즈/바디 = **×1.71** | 예전(×0.20 ~ ×1.12)보다 폭을 넓혔다 — 끝까지 가면 렌즈가 바디보다 비싸진다 |
| **일체형 ≠ 저렴** | 1/2.3" 슈퍼줌도 140만, 풀프레임 컴팩트(RX1R III) 649만 = 플래그십급 | 컴팩트도 ₩12만~₩220만. 고급 컴팩트는 상급 바디와 견준다 |
| **바디보다 렌즈** | 예산별 추천표의 공통 결론 | 상점 정보창에 "바디 급을 낮추고 렌즈에 투자" 팁 노출 |

### 3. 의도적으로 시장 비율을 따르지 않은 곳

- **1/2.3" 보급 컴팩트(₩12~34만)** — 실제 시장에 남은 모델이 거의 없어 참조가가 없다.
  시작 장비에서 올라가는 첫 사다리라 진행 난이도로 가격을 정했다.
- **150-600mm 컨템(₩38만)** — 시장의 "가성비 초망원"(시그마 C 계열 ≈ 150만) 포지션.
  AF 페널티 −1.5 · 1.9kg 이라는 게임 페널티와 짝을 이룬다.
- **조류 인식 AF 바디(₩175만)** · **위장 블라인드(₩22만)** — 시장가보다 게임 효용이 커서 프리미엄을 뒀다.
- **중형(MF)** — 엑셀에 중형이 없어 풀프레임 유사 모델 ×2.0(바디) · ×1.8(렌즈) 가정을 적용했다.

### 4. 라인업 자체는 그대로

게임 라인업(컴팩트 11 / 바디 10 / 렌즈 19 / TC 2 / 액세서리 5)은 유지했다.
실제 시장에 없는 DSLR(HB-F)·중형(MF-G) 계통은 "단종되어 싸게 넘어온 물건"이라는
게임 속 설정이 이미 있어, 가격만 그 설정에 맞게 조정했다.
