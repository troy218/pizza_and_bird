# P10. 출시 패키지 — 스토어 리스팅 · AAB · 릴리스 자동화

> 웨이브 **W1 착수 → W3 마감** · 규모 M · 담당 1명
> 의존: 없음 (착수). 마감 단계는 모든 기능이 main에 머지된 뒤 스크린샷/최종 문서 갱신.

---

## 1. 목표

현재 "APK를 만들어 주는 CI"에서 한 발 더 나아가 **플레이스토어 심사에 바로 낼 수 있는 상태**를 만든다:
AAB(Android App Bundle) 빌드·릴리스 서명 절차, 스토어 등록 텍스트(국/영), 개인정보·데이터 안전 양식 초안,
스크린샷 촬영 계획, 릴리스 운영 문서(버전 규칙·체크리스트).

## 2. 스토리 맥락

"할머니의 수첩"이 세상 밖으로 나가는 날 — 오프라인에서 완결된 이 게임의 철학(권한 0개, 수집 없는 세이브)이
스토어 설명문에서도 흐트러지지 않게 하는 것이 이 파트의 톤 관리 포인트다.
스토어 문구는 README의 감성을 그대로 계승한다: "피자를 굽고, 자전거를 타고, 새를 찍는."

## 3. 플레이어(=운영자) 경험

1. `v*` 태그 push → GitHub Actions가 **AAB + APK**를 만들고 Release에 첨부.
2. `store/` 폴더에 복붙 가능한 리스팅 텍스트(국/영), 데이터 안전·콘텐츠 등급 설문 답변 초안, 개인정보처리방침 md가 준비되어 있다.
3. `docs/RELEASE.md`의 체크리스트대로 눌러 나가면 심사 제출까지 막힘없이 완주.

## 4. 소유 파일

### 새 파일 (전액 소유)

| 파일 | 내용 |
|---|---|
| `.github/workflows/release-aab.yml` | `v*` 태그 트리거: `bundleRelease` → AAB 서명(시크릿 있을 때) → GitHub Release에 AAB+APK 첨부. **기존 `android-apk.yml`은 절대 수정 금지**(충돌 방지 — push CI와 분리). 시크릿 명명: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` — 주석에 등록 절차 명시. |
| `docs/RELEASE.md` | 릴리스 절차서: 버전 규칙(semver — v0.4.0 = 이번 시즌), versionCode 증가 규칙, 태그→빌드→Release→Play Console 업로드 순서, 사전 체크리스트(MapTest/kt_check/연기 테스트), 롤백 절차(이전 Release 재업로드), 스토어 갱신 주기 메모 |
| `store/listing_ko.md` | 플레이스토어 등록 문구 초안 — 제목(30자), 짧은 설명(80자), 전체 설명(4000자 한도, README 감성 계승 + v0.4.0 신기능: 계절·앨범·사이드 스토리·지역 특산 피자 반영), 키워드 메모 |
| `store/listing_en.md` | 영어 리스팅 (OVERVIEW Q4: 국문 기본·영어 병기). 새 이름·지역 표기는 로마자 표기법 통일 규칙 메모 포함 |
| `store/PRIVACY.md` | 개인정보처리방침 (정적 호스팅용 md): 수집 없음 명시 — "이 앱은 어떠한 개인정볼도 수집·전송하지 않습니다(완전 오프라인)" + 세이브 백업 코드는 사용자 기기 밖으로 나갈 때 사용자가 직접 복사한다는 점 명시 |
| `store/PLAY_FORMS.md` | Play Console 양식 초안: 데이터 안전(Data safety) = **수집/공유 없음** 체크표; 콘텐츠 등급(IARC) 설문 답변 초안(폭력/도박 등 전부 "없음" — 힐링 게임); 카테고리 제안(시뮬레이션/캐주얼), 타깃 연령=전체이용가 방향; 가격 정책 메모(묵음: 수익 모델 미정 — 유료 or 묵료는 OWNER 결정 사항으로 표시) |
| `store/SCREENSHOTS.md` | 스크린샷 8컷 촬영 스토리보드(아래 §5) + 촬영 가이드(에뮬 Fold/폰 해상도, 프레임 속 폰 베젤 유무, 폴아라이드 컷 연출) + **W3 최종 컷** 촬영 항목 체크리스트 |

### 패치 파일 (앵커 준수)

#### `app/build.gradle.kts` (전용 — 타 파트 무편집)
- 앵커: `defaultConfig { ... }` 블록의 `versionCode`/`versionName` 라인.
- 변경: 환경변수 우선 구조:
  ```kotlin
  versionCode = (providers.gradleProperty("VERSION_CODE").orNull ?: "1").toInt()
  versionName = providers.gradleProperty("VERSION_NAME").orNull ?: "0.4.0"
  ```
  (워크플로우가 태그에서 버전을 넣는다. 로컬에선 기본값.)
- `signingConfigs`/`buildTypes.release`: 시크릿 존재 시 키스토어 디코드+서명, 부재 시 debug 키(기존 동작 유지 — README의 CI 설명과 일치). 기존 블록을 **구조 변경 없이 감싼다**(디버그 키 폴더 필수).
- dependencies 추가 금지(오프라인·용량 원칙).

### 절대 건드리면 안 되는 것

- `.github/workflows/android-apk.yml` (push CI — 그대로 유지)
- 게임 소스 전체 (`app/src/**`) — 이 파트는 빌드/문서만
- `strings.xml`/아이콘 (필요한 리소스 변경은 W3에 별도 이슈로 제안만)
- README.md 로드맵 체크(통합 담당 소관) — 단 스토어 링크 섹션 신설은 W3 마감 시 허용

## 5. 스토어 스크린샷 스토리보드 (8컷)

| # | 장면 | 포인트 |
|---|---|---|
| 1 | 타이틀 화면 | 게임 로고+감성 배경, "피자와 새" 아이덴티티 |
| 2 | 서울 집 + 화덕에서 피자 굽기 (타이밍 게이지 보임) | 핵심 루프 ① |
| 3 | 자전거로 터널 진입 (봄, 꽃잎) | 핵심 루프 ② + 계절(P1) |
| 4 | 뷰파인더 촬영 순간 (AF 박스·거리 게이지) | 핵심 루프 ③ — README 뷰파인더 컷보다 업데이트된 것 |
| 5 | 폴아라이드 결과 카드 (3성 희귀종) | 보상 감성 |
| 6 | 앨범 탭 (그리드 한 화면 가득) | P3 신기능 |
| 7 | 겨울 밤 + 가로등 + 눈 쌓임 + 올빼미 | 낮밤·날씨 연출 |
| 8 | 지역 사이드 스토리 대화 장면 (제주 할머니) | P8 신기능 — "사람 이야기" 전달 |

- W1엔 1~4번 컷만 예시 촬영(현재 빌드 기준). **5~8번은 W3에 신기능 머지 후 최종 컷으로 교체** — 이 마감 작업이 이 파트의 마지막 체크리스트.
- P3의 `Album.best()` API로 대표 사진을 골라 컷 6 연출에 활용 가능(인터페이스 계약).
