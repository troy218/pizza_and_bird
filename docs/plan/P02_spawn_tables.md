# P2. 출현/희귀도 고도화 (계절 × 지역 × 시간대)

> 웨이브 **W2** · 규모 M · 담당 1명
> 의존: **P1 필요** (`Seasons.kt`의 `Season`, `Seasons.of(day)`를 import)

---

## 1. 목표

598종 전체의 출현 가중치를 **계절·지역 종류·시간대(낮/밤)**에 따라 세분화한다.
큐레이션 39종은 종별 표로, 나머지 공식종은 과(family)·서식지 규칙으로 커버한다.
README의 탐조지 표(“추천 시기”)와 게임 내 실제 출현이 **일치하도록** 만드는 것이 핵심 품질 기준이다.

## 2. 스토리 맥락

탐조의 리듬은 계절의 리듬이다 — 도요는 봄·가을에 갯벌을 지나고, 두루미는 겨울에 철원에 내리고,
팔색조는 여름 숲에서 운다. 게임이 이 리듬을 따라가야 "실제 한국 탐조 여행"이라는 설정이 살고
플레이어는 탐조지 표를 보고 **계절을 골라 떠나는 동기**를 얻는다. P8의 지역 대사도 이 테이블의
“이 계절의 새”를 참조한다.

## 3. 플레이어 경험

- 겨울 철원 평야에서 두루미·재두루미가 눈에 띄게 늘고(×2.0), 한여름엔 거의 보이지 않는다(×0.1).
- 봄·가을 갯벌·습지 지역에 도요류 출현이 피크를 찍는다.
- 낮/밤 조건은 기존 동작(`Birds.ALL`의 `active`)을 해치지 않고 그 위에 계절 배율을 얹는다.
- 희귀·전설 등급의 기본 절대 확률은 올리지 않는다 — **계절을 맞추면 찾기 쉽다**는 설계 (행운 수치 역할 유지).
- "이 계절에만 만나는 새"가 도감 수집의 장기 목표가 된다.

## 4. 소유 파일

### 새 파일 (전액 소유)

**`app/src/main/java/com/pizzaandbird/game/SpawnTables.kt`** — `[P02]` KDoc.

```kotlin
// [P02] 출현 가중치 테이블 — P1의 Season/Seasons를 import. Data.kt·BirdChecklist.kt는 읽기만 한다.
object SpawnTables {

    /** 월드씬 스폰이 종 하나의 최종 가중치를 얻는 단일 진입점. */
    fun weight(
        def: BirdDef,
        regionId: String,          // Regions id
        habitats: Set<String>,     // 해당 지역 서식지 풀 (regionPool 형태와 호환)
        season: Season,            // [P01]
        night: Boolean,            // state.isNight()
    ): Double

    /** 이 계절 이 지역의 대표 새 (P8 대사·추후 도감 힌트용). */
    fun highlights(regionId: String, s: Season): List<BirdDef>
}
```

구현 구조 (권장):

1. **종별 오버라이드 표 (큐레이션 39종)**: `mapOf("crane" to seasonal(봄=.15, 여름=.1, 가을=.6, 겨울=2.0), ...)`
   — README 탐조지 표의 "추천 시기"를 그대로 숫자로 옮긴다 (아래 §5 초안).
2. **일반종 규칙 엔진**: 오버라이드가 없으면 다음 규칙을 순서대로 적용해 배율 합성:
   - `def.family`/이름 분류 → 도요류(봄·가을 ×1.6), 오리·고니류(겨울 ×1.8, 여름 ×0.25), 제비·꾀꼬이류(여름 ×1.6, 겨울 ×0.1), 올빼미류(사계 ×1.0, 밤 조건은 기존 로직 소관), 텃새류(×1.0)
   - 서식지 상성: 지역 서식지 풀에 없는 서식지 전속 종은 ×0.2 (완전 0은 아니게 — 예외적 만남 연출)
   - 희귀도 보호: 등급이 희귀(3★) 이상이면 배율 결과를 0.25~4.0으로 클램프 (절대 확률 급등/소멸 방지)
3. **보정 상한**: 최종 weight는 기존 `def.weight` 대비 ×0.05~×3.0 클램프.

규칙:
- `Data.kt`, `BirdChecklist.kt` **수정 금지** — `def.id`/`name`/`family`/`habitats`/`active`/`weight`만 읽는다.
- 등급 변경·종 추가 같은 데이터 작업은 이 파트 범위가 아니다.

### 패치 파일 (앵커 준수)

#### `WorldScene.kt` — 스폰 가중치 1줄 교체 (예산 15줄 이내)
- 앵커 (trySpawnBird 낸, 문자열 검색):
  ```kotlin
  val weights = pool.map { it.weight * luckBoost(it) * weatherBirdMultiplier(it, currentWeather) }
  ```
- 교체 내용 (예시):
  ```kotlin
  val season = Seasons.of(state.day)                    // [P01]
  val weights = pool.map {                              // [P02] 계절 반영
      it.weight * luckBoost(it) * weatherBirdMultiplier(it, currentWeather) *
          SpawnTables.weight(it, region.id, region.habitats, season, state.isNight())
  }
  ```
- `regionPool()`·야간 조건·스폰 위치 룰(최대 3마리, 거리 7~20칸) 등 **다른 로직 무수정**.
- 기존 평균 출현 빈도가 크게 변하지 않도록, 가중치 총합이 현재 대비 0.5~2배 범위에 들어오는지 `tools/MapTest.kt` 방식의 검증 하나 추가 금지 → 대신 아래 §6 검증 스크립트로 확인.

## 5. 종별 계절 배율 초안 (큐레이션 39종, README 탐조지 표 기준)

| 새 | 봄 | 여름 | 가을 | 겨울 | 근거 |
|---|---:|---:|---:|---:|---|
| 두루미 / 재두루미 / 흑두루미 | 0.15 | 0.10 | 0.60 | **2.0** | 철원·순천만 월동지 11~2월 |
| 팔색조 | 0.3 | **2.0** | 0.4 | 0.05 | 여름 번식조 |
| 도요류(청도요·붉은어깨도요·검은머리물떼새) | **1.8** | 0.7 | **1.8** | 0.4 | 나눔터·간월암 봄가을 |
| 기러기·고니류(큰기러기·큰고니·가창오리) | 0.2 | 0.1 | 0.8 | **2.0** | 월동 |
| 저어새 | **1.5** | 1.2 | 1.0 | 0.3 | 번식 여름~초가을 |
| 청둥오리·쇠오리 · 원앙 | 0.9 | 0.5 | 1.2 | **1.5** | 겨울 오리 테마 |
| 물수리 | 0.6 | 0.4 | **1.6** | 1.0 | 왕피천 가을 연어 |
| 뻐꾸기·개개비·꾀꼬리류 | 1.2 | **1.8** | 0.5 | 0.05 | 여름조 |
| 올빼미·부엉이류 | 1.0 | 1.0 | 1.0 | 1.2 | 텃새성 (밤 조건 기존 유지) |
| 딱따구리류 | 1.2 | 1.0 | 1.0 | 1.0 | 텃새 |
| 맹금류(황조롱이·참매·수리) | 1.0 | 0.9 | 1.1 | 1.2 | 겨울 관찰 용이 |
| 흔함 텃새(참새·까치·직박구리·박새·비둘기류) | 1.0 | 1.0 | 1.0 | 1.0 | 기본 유지 |
| 따오기·황새 | 1.2 | 0.8 | 0.8 | **1.3** | 우포늪·철원 겨울 복원 개체 암시 |

- 표에 없는 공식종: 규칙 엔진(도요류/오리류/여름조/텃새/올빼미류) 사전으로 처리.
- **지역 상성 배율 별도 표** 예: 수리부엉이 = 산/숲 지역 ×1.5, 도시 ×0.3. (기존 큐레이션 지역 한정은 `regionPool`이 이미 처리 — 여기선 미세 조정만)
