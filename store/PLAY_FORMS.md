# Play Console 양식 답변 초안 — 피자와 새

> [P10] Play Console「앱 콘텐츠」섹션 복붙용 초안. 철학: **힐링 게임 — 물어볼 것이 없는 앱**.
> 각 답변 옆의 [근거]는 심사 대응용 출처 표기이며 Console에는 입력하지 않는다.
> ⚠️ 소유자(OWNER) 확정 사항은 ❓로 표시했다. W3 마감 시 통합 QA 결과를 근거에 반영.

## 1. 데이터 안전 (Data safety)

| 질문 | 답변 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유합니까? | **아니오** |
| → 이후 세부 질문(수집 항목·목적·전송 암호화·삭제 요청) | 전부 표시되지 않음(비수집으로 처리) |

[근거] 완전 오프라인 — `AndroidManifest.xml`에 INTERNET 권한 미선언, 권한 총 0개.
개인정보처리방침(`store/PRIVACY.md`) §2–§4와 일치.
검증 방법(릴리스마다): `aapt dump permissions app-release.aab` → 권한 0개 확인 후 스크린샷 보관.

|---|---|
| 폭력적 표현 | 없음 (동물이 놀라 날아가는 연출뿐 — 폭력 연출 아님) |

| 욕설·혐오 표현 | 없음 |

| 사용자 상호작용(채팅·이미지 공유·음성) | 없음 — 완전 싱글 플레이, 공유 기능 없음 |

| 디지털 상품 구매 (앱 내 결제) | 없음 — ❓가격 정책 확정 시 갱신 (§5) |
