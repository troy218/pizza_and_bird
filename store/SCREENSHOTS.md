## 2. 촬영 가이드

### 2.1 에뮬레이터/기기 설정

| 대상 | 설정 | 산출물 |
|---|---|---|
| 폰 | Pixel 7 (1080×2400) 또는 동급, API 35, 시스템 UI 숨김(몰입 모드 자동) | `cut*_phone.png` 9:16 |
| 폴더블 | Pixel Fold(펼침, 2208×1768) | `cut*_fold.png` — Console 폴더블/태블릿 슬롯 |
| 태블릿 | Pixel Tablet(1600×2560) — 7인치/10인치 슬롯용 | `cut*_tablet.png` |

- **폰 베젤 프레임**: 넣지 않는다(기본). Console 업로드 원본은 순수 게임 화면.
  마케팅 배너 등에 프레임 연출이 필요하면 별도 파생본을 만든다.
- **확대/압축 금지**: 스크린샷은 화면 그대로. 최소변·비율 요건(폰 16:9 또는 9:16 권장,
  최소 320px ~ 최대 3840px)은 Console 요구사항 페이지에서 최종 확인.

### 2.2 장면 세팅 방법 (게임 내)

- 시간대·날씨는 게임이 흘러가며 바뀐다(5분=1일, 날씨 1~2분). 원하는 장면이 나올 때까지
  대기 후 촬영하거나, 잠자기로 시간을 점프시켜 조절.
- 계절(P1 머지 후): 게임 날짜가 계절을 결정 — 세이브를 백업 코드로 뜬 뒤 날짜를 맞춰 촬영하면 재현이 쉽다.
- 희귀종 유도: 행운 수치를 높인 상태(피자 걸작 + 장식 + 고양이)에서 대기.
- 촬영 컷 프리뷰: `tools/preview_viewfinder.py`, `tools/camera_lab/index.html`로 연출을 미리 튜닝 가능(게임 코드 영향 없음).

### 2.3 폴라로이드 컷(컷 5) 연출

- 결과 카드가 살짝 기울어진 인화지로 뜨는 화면을 그대로 캡처하고, 하단 여백은 잘라내지 않는다
  (카드 자체가 여백을 포함한 그래픽이므로).
- 3성 판정 직후 별이 다 찍힌 프레임을 잡기 위해 촬영 → 결과 → 즉시 캡처 반복.
