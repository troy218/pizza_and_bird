✨ 바뀐 점 (v0.2.1 플랫 스틱 → v0.3.3)

  • 유리 베이스 + 금속 림 — 그라데이션 링, 안쪽 홈 2중 라인, 눈금 32개(4방위 강조)
  • 3D 스틱 캡 — 스페큘러/하단 음영/접촉 그림자, 민 방향으로 축이 기울어짐
  • 피자 엠블럼 — 캡 가운데 픽셀 피자 🍕
  • 게이지 호 — 민 만큼 링이 채워짐 (아날로그 입력 시각화)
  • 방향 셰브론 — 입력 방향으로 앰버 점등 + 글로우
  • 달리기 링 — 🏃 중에 베이스 밖 점선 회전
  • 스프링 복귀 — 놓으면 베이스·캡이 부드럽게 홈으로 (이전엔 즉시 튐)
  • 탭 보존 — 스틱 구역에서도 움직임 없이 떼면 월드
  • 아날로그 이동 — 스틱 크기만큼 속도 50~100%
  • 아크 버튼 입체감 — 그림자 + 글로스 + 눌림 오므림
