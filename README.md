# 🍕 Pizza and Bird : 피자와 새 🐦

> 피자를 굽고, 자전거를 타고, 새를 찍는 — **완전 오프라인 픽셀 힐링 게임**
>
> 한국의 실제 지역을 배경으로, 화덕에서 피자를 구워 배낭에 챙겨 넣고
> 자전거로 터널을 넘어 전국을 돌아다니며 새 사진을 찍어 도감을 채우는 게임입니다.

- 📸 **사진 결과 화면 리뉴얼**: 폴라로이드 스타일 + 등급별 액센트 + 별 팝인 연출 + 첫 발견 리본
- 🐦 **새 그래픽 전면 재작업**: 아웃라인·눈 하이라이트·깃털 디테일, 대기/날개짓 2프레임 애니메이션, 학류(두루미) 전용 와더 실루엣

- 🎮 입력 개선: 탭은 손을 뗄 때 반응(드래그와 구분), 카메라/메뉴 버튼 간격 확보, 키 반복 입력 방지
- 🗺️ 미니맵을 탭하면 큰 지도가 열려요 (기존 문서에 있던 기능 구현)
- ✨ 화면에 꽃가루 입자·버튼 하이라이트 등 그래픽 다듬기, 희귀새/의뢰새 출현 알림

## 🎮 게임 소개

| | |
|---|---|

### 핵심 루프

1. 🏠 **집에서 피자 굽기** — 화덕(기본 제공)에서 타이밍 미니게임으로 피자를 굽는다
2. 🚲 **자전거 여행** — 포켓몬처럼 자전거를 타고 터널을 넘어 다른 지역으로! (텔레포트 없음)
3. 📷 **탐조** — 필드에 나타난 새를 카메라 모드로 촬영 (가까이 가면 도망감!)
4. 👨‍🔬 **보리 박사의 의뢰** — 부탁받은 새를 찍으면 보수 ₩ 획득
5. 📚 **도감 채우기** — 새별 촬영 횟수가 기록되는 도감
6. 📷 **카메라 업그레이드** — 돈을 모아 더 멀리서 찍을 수 있는 카메라로
7. 🍕 **피자 먹기** — 배고픔 수치 회복 + 행운 수치 상승
8. ☘️ **행운 수치** — 높을수록 희귀한 새(팔색조, 두루미!)가 더 자주 출현
9. 📦 **이사** — 마음에 드는 지역을 방문한 뒤 집을 이전할 수 있음

### 지역 (실제 한국 지역 9곳, 지속 추가 예정)

서울 · 인천 · 춘천 · 강릉 · 속초 · 대전 · 광주 · 부산 · 제주

## 🛠️ 빌드 방법

### Android Studio
1. 이 저장소를 Clone 후 Android Studio로 열기
2. Sync → Run ▶

### 커맨드라인
```bash
./gradlew assembleDebug     # debug APK
./gradlew assembleRelease   # release APK (시크릿 없으면 debug 키로 서명)
```
APK 위치: `app/build/outputs/apk/`

요구 사항: JDK 17, Android SDK (API 35)

---

## 📦 GitHub Actions로 베타 APK 받기 (CI)

이 저장소는 **push할 때마다 APK를 자동 빌드**합니다.

1. GitHub 저장소 → **Actions** 탭 → `Android APK Build` 워크플로우 확인
2. 빌드가 끝나면 해당 실행(run) 페이지 하단 **Artifacts**에서 APK 다운로드
   - `pizza-and-bird-debug-apk` — 디버그 APK (베타 테스트용 추천)
   - `pizza-and-bird-release-apk` — 릴리스 APK
3. **정식 릴리스 배포**: `v*` 태그를 push하면 GitHub Release에 APK가 첨부됩니다
   ```bash
   git tag v0.1.0 && git push origin v0.1.0
   ```
4. (권장) 스토어 출시 전 시크릿에 키스토어 등록 → 워크플로우 파일 상단 주석 참고

> 베타 테스트 배포가 목적이라면 debug APK을 그냥 나눠주면 됩니다.
> 설치 시 "출처를 알 수 없는 앱" 허용이 필요할 수 있어요.

## 🕹️ 조작법

| 입력 | 동작 |
|---|---|
| 왼쪽 D패드 (드래그) | 이동 (8방향) |
| **A** 버튼 | 대화 / 상호작용 (NPC·화덕·침대·이사박스) |
| **B** 버튼 | 자전거 타기/내리기 🚲 |
| 📷 버튼 | 카메라 모드 (시간이 느려지고, 새를 탭하면 촬영) |
| ☰ 버튼 | 메뉴 (상태 / 피자 먹기 / 도감 / 설정) |
| 우측 상단 원형 지도 | 탭하면 큰 지도 |
| 키보드 | WASD/화살표 이동, Z=A, X=B, C=카메라, M=메뉴 |

## 🗂️ 프로젝트 구조

```
app/src/main/java/com/pizzaandbird/game/
├── MainActivity.kt      액티비티 (몰입 모드, 키 입력)
├── GameView.kt          SurfaceView 게임 루프 (60fps)
├── Game.kt              씬 관리, 가상 해상도 스케일링, 페이드 전환
├── Input.kt             멀티터치 D패드 + 버튼 + 키보드 입력
├── Assets.kt            모든 픽셀 아트를 코드로 생성 (이미지 파일 0개!)
├── Data.kt              새 12종 / 지역 9곳 / 피자 / 카메라 데이터 정의
├── GameState.kt         진행 상황 + 오프라인 저장 (JSON)
├── Maps.kt              타일, 지역 맵 절차 생성, 플레이어/새/NPC 엔티티
├── Scenes.kt            씬 베이스 + 타이틀 화면
├── RegionSelect.kt      정착/이사 지역 선택 UI
├── WorldScene.kt        월드 탐험 (자전거·터널·탐조·의뢰)
├── HomeScene.kt         집 내부 (화덕·침대·이사·장식 슬롯)
├── Hud.kt               스탯 바 + 원형 한국 미니맵 + 컨트롤
└── Overlays.kt          대화상자 / 메뉴·도감 / 피자 굽기 / 사진 결과 / 지도

tools/make_icons.py      런처 아이콘 생성 (순수 Python, 의존성 0)
tools/MapTest.kt         맵 로직 검증 스크립트 (81개 맵 조합 자동 테스트)
```

### 콘텐츠 추가 방법
- **새 종류 추가**: `Data.kt`의 `Birds.ALL`에 항목 추가 → 도감/스폰/박사 의뢰에 자동 반영
- **지역 추가**: `Regions.ALL` + `LINKS`에 연결 추가 → 맵은 절차 생성
- **피자 종류/장식 소품**: `PizzaQ` / `T.DECOR` 슬롯 (설계 문서 참고)
